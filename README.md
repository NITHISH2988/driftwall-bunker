# Esper Studio

An independent digital studio helping businesses build a confident, useful presence online. The site is a static marketing experience: it does not collect or store form submissions. The project brief opens in the visitor’s email app addressed to `support.esper@gmail.com`.

## Run locally

Install the dependencies with `npm install`, then start the app with `npm run dev`.

## Deployment

Vercel builds the site with `npm run build`. There is no database, sign-in flow, or server-side lead storage.
